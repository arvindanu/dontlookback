# DON'T LOOK BACK

A dark, cinematic 2D psychological-horror survival runner for Android (Godot 4, GDScript, zero third-party dependencies).
You run automatically. Something is always behind you. You can turn around and look — and it gets closer the longer you do.

* **Engine:** Godot 4.3+ (standard build, GL Compatibility renderer — runs on low/mid Android devices)
* **Orientation:** landscape 16:9 (base 1280x720, sensor-landscape so both landscape directions work)
* **Size:** ~2 MB of assets, no network, only the `VIBRATE` permission

> **Status — please read.** The whole project was authored without access to a Godot editor or the Android SDK, so it
> has been statically checked (`tools/lint_gd.py`) and its audio/icons were generated and verified, but it has **not been
> run inside Godot yet**, and **no APK binary is included** — an APK can only be produced by Godot's exporter.
> Follow [`docs/BUILD_ANDROID.md`](docs/BUILD_ANDROID.md) (about 15 minutes, or push to GitHub and let CI build it).
> On the very first open, expect to fix at most a few small engine-version nits; the code is small, typed and commented.

## Controls

| Action | Touch (landscape) | Keyboard |
|---|---|---|
| **Jump** (hold = higher, tap = short hop) | right thumb, big button | Space / W / Up |
| **Slide** (hold to stay low; in air = fast-fall dive) | right thumb, left button | S / Down |
| **Dash** (i-frames, smashes anything but pits; 2 s cooldown) | left thumb, small button | Shift / D / Right |
| **Look back** (hold) | left thumb, big button | A / L / Left |
| Pause | top-right button / Android Back | Esc / P |

Multi-touch is real: hold LOOK with one thumb while jumping and sliding with the other.

## The rules of the world

* **Read the rim colour.** Every hazard glows the colour of the answer: **amber = jump**, **cyan = slide**, **red = dash**, with a matching chevron above it.
  * Gravestones and bone spikes → jump. Pits → jump. Hanging slabs and crows → slide. Thorn walls → dash through (the only thing that can pass them).
* **The creature.** `gap` is its distance behind you. Looking closes the gap faster the longer you stare (and it remembers — peeks add up). After 1.5 s of staring it **lunges**. Hits knock it closer; if it reaches you, you're consumed.
* **Risk / reward.** Every ~10–18 s something glints *behind* you (Lantern: pushes it back and widens your light · Relic: score x2 · Ward: absorbs one hit). You must turn and hold your gaze ~0.45 s to grab it — while it creeps closer.
* **Progression.** Speed ramps 500 → 1060 px/s; new hazards unlock with distance (spikes/slabs → pits → combos → thorn walls → crows → chained combos); the world drains from dusk-violet to blood-black, the moon swells and reddens, eyes appear in the trees, the creature grows and gets bolder. Random events: whispers, blackouts, fog, false-creature scares, creature surges.
* **Meta.** Shards buy scarf colours (Ash · Ember · Bone · Blood · Void · Gold). Combo of shards raises the score multiplier (x1 → x3).

## Movement feel (what changed vs. the prototype)

`scripts/game/player_ctl.gd` is a small, tunable physics model:

* speed *eases* toward a state goal (accel 1500 / decel 2400 px/s²) — stumbles, slides, dashes and looking back all change the goal, so nothing snaps
* coyote time (90 ms) + jump buffering (130 ms) + variable jump height + heavier fall gravity
* dash has an attack/decay curve (not a constant boost) with i-frames and a short hit-stop on impact
* slide is hold-to-extend (0.36–0.95 s); pressing slide in the air dives and chains straight into a slide on landing
* squash & stretch on a damped spring; procedural two-bone IK legs/arms blended between run / air / slide / dash poses; simulated scarf
* forgiving hit-boxes (shrunk on the sides/tops of hazards) and hit-stop + camera punch make impacts read without being unfair

```
├── export_presets.cfg       ready-made "Android" export preset (APK, arm64 + armv7)
├── assets/
│   ├── images/              launcher icons (generated by tools/generate_icons.py)
│   ├── sounds/              26 WAVs: SFX + seamless ambience loops (tools/generate_audio.py)
│   ├── music/               <- DROP YOUR MUSIC HERE (.ogg/.mp3/.wav) — auto-detected, see README.txt
│   └── shaders/post_fx.gdshader   lighting mask, vignette, aberration, glitch, grain, flashes
├── scenes/                  main_menu · game · hud · game_over
├── scripts/
│   ├── autoload/            game_state.gd (save, settings, input map, haptics) · audio_manager.gd
│   ├── core/                cfg.gd (constants) · gfx.gd (draw helpers, IK)
│   ├── game/                game.gd (run controller) · player_ctl · creature · obstacle · world_gen · particle_system · pickup
│   ├── render/              world_renderer · glow_renderer · post_fx + background/obstacle/character/creature drawers
│   └── ui/                  hud (touch controls) · main_menu · game_over · ui_kit
├── tools/                   build_android.sh · make_release_keystore.sh · generate_*.py · lint_gd.py
├── docs/BUILD_ANDROID.md    build, sign and publish guide
└── .github/workflows/       CI that builds the APK for you
```

Rendering is three stacked layers: **world** (darkened by the shader) → **post-FX** (`post_fx.gdshader`) → **glow** (additive, drawn *above* the darkness so hazard rims, shards and the creature's eyes always burn through). Everything is drawn procedurally with `_draw()` — there are no sprite sheets to ship.

## Tuning cheat-sheet

| Want to change… | Edit |
|---|---|
| Jump height / gravity / coyote / buffer / slide & dash timings | constants at the top of `scripts/game/player_ctl.gd` |
| Run speed ramp, darkness curve, event timing | `_update_play()`, `_process()` in `scripts/game/game.gd` |
| How aggressive the creature is | `Creature.update()` / `rest_gap()` in `scripts/game/creature.gd` |
| Which hazards appear when, spacing, shard placement | `_spawn_pattern()` in `scripts/game/world_gen.gd` |
| Hazard size & colour language | `scripts/render/obstacle_drawer.gd`, `Cfg.COL_*` |
| Touch-button positions/sizes | `BTN` in `scripts/ui/hud.gd` |
| Sound design | edit/re-run `tools/generate_audio.py`, or replace the WAVs (same filenames) |
